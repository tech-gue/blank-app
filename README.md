# 🎈 Blank app template

## Overview

This repository is a minimal [Streamlit](https://streamlit.io/) starter app. It provides a blank `streamlit_app.py` entry point and a `requirements.txt`, so you can quickly build and deploy your own interactive Python web app.

A simple Streamlit app template for you to modify!

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```

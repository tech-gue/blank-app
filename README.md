# 🎈 Blank app template

A simple Streamlit app template for you to modify!

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```

## Usage

Once the app is running, Streamlit prints a local URL (by default http://localhost:8501). Open it in your browser to view the app. Edit `streamlit_app.py` and save; Streamlit will offer to rerun the app automatically. Stop the server with `Ctrl+C`.

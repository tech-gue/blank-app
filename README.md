# 🎈 Blank app

A minimal [Streamlit](https://streamlit.io) app, ready to be customised into your own data app.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

## Features

- Single-file Streamlit app (`streamlit_app.py`) that is easy to extend
- Minimal dependencies (just `streamlit`)
- Dev container configuration for a ready-to-use development environment
- Can be deployed to Streamlit Community Cloud

## Getting Started

1. Install the requirements:

   ```
   pip install -r requirements.txt
   ```

2. Run the app:

   ```
   streamlit run streamlit_app.py
   ```

3. Open the local URL printed in the terminal (usually http://localhost:8501) and start editing `streamlit_app.py`.
